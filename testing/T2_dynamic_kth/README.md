# T2 动态序列区间第 k 大 本地测评

本目录是自建的本地测评程序，**不参与正式测评**，仅用于在提交前核对正确性与
性能。测评方式与公开的 `testing/T0_ab` 保持一致：只收集
`problems/T2_dynamic_kth/src/` 下的全部 `.cpp`，用本目录 `include/` 中的官方
接口副本编译，不使用题目自带的 `CMakeLists.txt`。

用例构成：

| 档位 | 规模 | 核对方式 |
| --- | --- | --- |
| 对拍 | 8 组极小规模随机操作序列 | 每个查询与暴力解核对 |
| 基础 | 10 组 `N,Q <= 1000`（含空初始、单元素） | 每个查询与暴力解核对 |
| 集中值域 | 3 组取值压在窄区间的用例 | 每个查询与暴力解核对（检验候选退化兜底） |
| 拓展 1 | 5 组 `N=1e5, Q=4e4` | 每个查询与暴力解核对 |
| 拓展 2 | 5 组 `N=5e6, Q=2e4` | 全量操作后每 100 个查询抽验一次 |

暴力参考为 `std::vector` + `std::nth_element`。拓展 2 的暴力单次查询是 O(N)，
全量核对代价过高，因此只抽样核对；实现耗时（构造 + 全部操作）单独统计，便于
对照 1000 ms 的限时。

运行方式：

```bash
cmake -S testing/T2_dynamic_kth -B /tmp/pip27-t2-grader
cmake --build /tmp/pip27-t2-grader -j
/tmp/pip27-t2-grader/grader          # 可选参数：随机种子
```
